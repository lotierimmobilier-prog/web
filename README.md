# Site LOTIER Immobilier

Site vitrine statique (HTML, CSS, JavaScript), sans étape de compilation.

- `index.html` : page d'accueil
- `css/styles.css` : styles, avec les jetons de la charte en variables CSS
- `js/main.js` : onglets de recherche et sélecteur « Quel est votre projet ? »
- `assets/` : logo

Mise en ligne : copier le contenu du dossier à la racine de l'hébergement (OVH).

À compléter avant publication : photos, annonces, avis, articles, adresses de Montpellier et de Rodilhan, horaires, pages légales. Les champs concernés sont écrits entre crochets dans `index.html`.
